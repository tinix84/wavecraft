05

Human direct-file test card

Automatic file URL access is blocked by the browser policy. A person must perform this test in Windows Chrome and Edge.

  1. Download the release HTML, notices, checklist, and sample fixtures.
  2. Disconnect networking.
  3. Open the HTML directly from disk in Chrome.
  4. Import the sample YAML and PNG through the file inputs.
  5. Download the proof ZIP.
  6. Reopen that ZIP and confirm all three comparison fields are true.
  7. Change the zoom and panel width.
  8. Click the center cross and check coordinates within two SVG units.
  9. Write a recovery revision and wait for transaction complete.
  10. Reload this same HTML file and read the recovery revision.
  11. Confirm the recovery payload comparison fields are true.
  12. Enable simulated denied recovery storage and attempt a write.
  13. Download and reopen another ZIP while storage remains denied.
  14. Save the diagnostic report and record the browser version.
  15. Repeat this test in Edge.
